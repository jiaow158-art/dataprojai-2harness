## 过程实锤与修复

- **sqlite3 连接线程绑定**：APScheduler job 线程/广播/心跳线程与主线程共享连接默认
  `check_same_thread=True` 全部静默失败（广播空表实锤）→ scheduler 侧 `check_same_thread=False`
  （短事务模块级串行化）；压测用每线程独立连接还原真实跨进程语义
- **APScheduler 3.11**：`Job.next_run_time` 属性兼容（getattr 兜底）；Windows 需 tzdata
  （随 apscheduler 安装）
- **SCHEMA 幂等 replace** 与新表 `IF NOT EXISTS` 写法相撞（双写语法错）→ 新表回归裸 CREATE TABLE
- **deadline 判定与真实时钟解耦**（`_now_minute` 可注入）——否则 13:00 后测试集翻红
- 密钥部署：INSIGHT_ADMIN_TOKEN 经注册表 User 级 + pm2 `--update-env` 进 BFF/api/scheduler，
  值全程不出终端（红线 upheld）
