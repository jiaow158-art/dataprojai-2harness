**Goal:** 从"本机常驻试点"走到"服务器正式运行 + 管理后台 v1 + 运行规范定稿"，完成正式切换（spec §12 M4 行）；试点期遗留问题清零。

### Task 0: 裁定项（需用户输入）

- [ ] **服务器**：什么时候有？规格（CPU/内存/盘）、系统版本；能否访问 DWS(121.37.200.214:8000) 与 DeepSeek API（外网 443）；Docker 可装否——四项决定 A 线开工日

- [ ] **并发规模**：白名单试点 5 人 → 正式开放多少人？（网关 MAX_CONCURRENT_TASKS=3、D7 按 10 人设计——规模变了要重估 soak）

- [ ] **数据保留策略**：任务/事件库与报告目录的保留期（无限 vs N 天滚动）——影响备份方案
