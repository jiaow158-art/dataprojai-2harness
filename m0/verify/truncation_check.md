## 4. >200 行完整性实证（Step 3，D13 核心断言）

**全量扫描**：`m0/results/` 56 个落盘文件（T14 53 个 + T7 3 个）逐个解析，
**全部满足 row_count == len(data)**（含 0 行文件），`truncated` 全为 false。
**row_count > 200 的文件仅 1 个**（T14 的查询均为聚合/小结果，计划预期的
"任选 2 个 >200 行"实际只有 1 个候选，如实记录）：

| 项 | 实证值 |
|---|---|
| result_ref | `r-20260908123825-44344-1`（T7 探针，855 行） |
| SQL | `SELECT calmonth, plant, count(*) AS row_cnt FROM dm.dm_fin_stock_detail_accage_t_2023 WHERE calmonth >= '202601' GROUP BY calmonth, plant` |
| row_count | 855 |
| len(data) | **855（== row_count，落盘完整）** |
| truncated | false |
| 截断反事实 | 若走 200 行预览截断，len(data)=200 ≠ 855，且 GROUP BY 组合会缺失（202601–202609 × 131 工厂 = 855 组全在） |

**逐行重导对照**（同 SQL 于 2026-09-09 重跑）：重导仍返回 **855 行**（行数一致）；
键集合（calmonth × plant）**完全一致**（855 组，无缺失组）；36 个组数值微差，
全部集中在 `calmonth='202609'`（当月账期仍在 ETL 持续入库，如 1520 工厂 686,926→687,403），
202601–202608 各月合计逐月**分毫不差**（5,731,691 / 5,748,478 / 5,824,655 / 5,924,015 /
6,027,624 / 6,129,562 / 6,228,938 / 6,324,581）。总差 3,227 行 = 全部来自 202609。
→ 判定：**数据漂移（活库当月增量），不是截断**；截断会表现为"尾部组缺失/行数<855"，
而非"键全同、当月数值微增"。

**汇总数来自完整数据而非 200 行预览的对照证明**（本次唯一 >200 行样本自身即证据）：
落盘文件内 `sum(row_cnt) = 54,280,590`，即报告链路确实取回了 5,428 万行的聚合输入——
远超 200 行预览通道容量。dsh 报告侧对应口径（库存域 202608 单月 632.5 万行输入 →
库存金额 14.74 亿）与重导真值 14.74 亿一致（compare 指标 4 PASS）。

**补充（T14 最大落盘文件 111 行，`r-20260909092142-4464-21`）**：data len=111==row_count，
`truncated=false`。注意该文件（`dm_ar_receivable_accage_t` 按公司 20260831 汇总 13.08 亿）
是 dsh 的中间探测**候选**之一，最终 KPI 采用的是 `dm_ar_analysis_rpt_f` 口径 18.11 亿
（对照 `r-20260909092436-4464-36`，cnt=105,920 行、recv_yi=18.11==报告 KPI）——
报告数字与该口径的**全量**落盘聚合一致，而非任何 200 行预览的产物。

## 5. 结论

| 断言 | 判定 | 依据 |
|---|---|---|
| 落盘不截断（row_count==data len） | **成立** | 56/56 文件逐项相等；唯一 >200 行样本 855=855，截断反事实不成立 |
| 报告数字来自完整数据 | **成立** | 18.11 亿 == 全量落盘聚合（r-…-36）；14.74 亿 == 重导真值（指标 4 PASS） |
| 同 SQL 重导无数据漂移（金样口径） | **成立**（当月活表除外） | 指标 1/2/3/4/7 重导与金样实测同值；855 行样本 202601–202608 逐月零漂移，仅 202609 当月增量 |
| 指标级 compare 全 PASS | **未达成（4 FAIL，均非截断/非能力）** | 1 项已知口径分歧（33.63 vs 18.11，金样口径未沉淀的隐性知识）+ 2 项维度标签伪影（5501/GD03，金样自检同样 FAIL）+ 1 项呈现方式差（50508，金样正文亦无此数） |

**「无静默截断」成立。** 遗留登记（不属本任务修）：① ar-knowledge 未沉淀金样应收口径
（科目白名单+正余额），复现级一致需 M1 补文档（T14 §7.2 同项）；② metrics.json 指标 5
expect_hint 中 5503=研发 1,788 万与重导结果（5503=131 万，与 5504=物流 1,283 万的
expect_hint 行序冲突）不符，疑为 hints 转录行序笔误，真值以 fetchall 全行为准；
③ compare_report.py 的指标检查用 `fetchone` 单值 + 字面子串匹配，对多行/维度列
SQL 会产生伪 FAIL（金样自检亦 2 FAIL），M1 可改为「全行任一数值命中」语义。
